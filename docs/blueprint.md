# **App Name**: CyberHub Manager

## Core Features:

- Real-time Station Monitoring: Display the real-time status (available/in use) of each console (PS5, PC, VIP PS5) and the VR simulator.
- Online Reservation System: Allow clients to reserve gaming stations online, view available time slots, and manage their bookings.
- QR Code Generation & Management: Automatically generate a unique QR code upon payment, associating it with the client's profile (name, contact). The code is deliverable via email/WhatsApp.
- QR Code Scanner (Admin): Admin interface to scan QR codes for check-in, bonus redemption, or subscription management (adding/subtracting hours).
- Client Profile Management (Admin): Admin interface to create, view, and manage client profiles, subscription status, and bonus points.
- Usage Analytics Dashboard (Admin): Admin dashboard providing statistics on console usage, peak hours, popular days, and revenue trends.
- Loyalty and Bonus Recommendations (AI): Generative AI tool that analyzes customer data and recommends customized bonuses or rewards based on usage patterns and preferences to enhance customer engagement and retention. (Requires data collected through QR code checkins).

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) to reflect the energy and digital nature of gaming.
- Background color: Dark gray (#28282B) to create a modern and immersive atmosphere.
- Accent color: Neon purple (#D400FF) to highlight interactive elements and calls to action.
- Body and headline font: 'Space Grotesk' sans-serif font for a techy, modern feel. If longer text is required, use 'Inter' for the body of the text instead.
- Code font: 'Source Code Pro' for any displayed code (if needed).
- Use sharp, minimalist icons representing gaming consoles, VR gear, and user interface actions.
- Subtle transitions and loading animations to provide a smooth user experience.
